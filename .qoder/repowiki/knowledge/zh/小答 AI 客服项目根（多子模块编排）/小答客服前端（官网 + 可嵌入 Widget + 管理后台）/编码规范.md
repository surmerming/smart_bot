- 每个 HTML 页面在 src 下对应一个同名的 .ts 文件作为入口（main.ts→index.html、agent.ts→agent.html、dashboard.ts→dashboard.html、kb.ts→kb.html），并在 vite.config.ts 中显式注册为 Rollup input。
- UI 样式以 CSS 模板字符串常量（如 WIDGET_CSS）内联到组件 shadow DOM 中，避免外部样式污染，保持 Web Component 自包含。
- 所有后端交互统一走 api.ts 与 sse-client.ts 两个模块，Widget 与后台页面不直接调用 fetch。
- Web Component 通过 static get observedAttributes 声明属性，并在 attributeChangedCallback 中同步内部状态，再通过 connectedCallback 绑定事件与初始化渲染。
