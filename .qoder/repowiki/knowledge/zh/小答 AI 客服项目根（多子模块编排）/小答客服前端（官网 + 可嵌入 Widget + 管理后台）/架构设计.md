单仓多入口 SPA：vite.config.ts 通过 Rollup input 将 index.html、agent.html、dashboard.html、kb.html 四个 HTML 模板分别编译为独立产物；src/main.ts 作为官网入口，仅负责加载 styles.css、注册 ChatWidget Web Component 并调用 renderSite 渲染静态页面。

- 业务模块按场景拆分：site.ts 渲染官网静态内容（导航/Hero/FAQ/CTA），widget.ts 实现 `<xd-chat-widget>` Web Component（floating 悬浮按钮与 inline 内嵌两种 mode，含消息气泡、CSAT 评分、OTP 验证、免责声明等 UI），agent.ts/dashboard.ts/kb.ts 各自对应 agent.html、dashboard.html、kb.html 的管理后台页面。
- 网络层集中在 api.ts（REST 封装）和 sse-client.ts（POST + text/event-stream 流式解析，使用 ReadableStream 逐事件回调 SSEEvent）。Widget 与后台页面均通过这些模块消费后端接口。
- 组件隔离：ChatWidget 使用 Shadow DOM（attachShadow({mode:'open'})）+ 内联 CSS 字符串，对外暴露 `mode`、`api-base`、`brand` 三个 observedAttributes，使其可被任意第三方站点一行 `<xd-chat-widget>` 引入。
- 开发时 vite server 把 /api 与 /ws 代理到 http://127.0.0.1:8000，生产由网关或同源部署接管。
