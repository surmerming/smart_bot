本模块由两类工件组成：
- `.github/workflows/ci.yml`：GitHub Actions 流水线，在 push main 与 PR 时并行执行 `backend`（Python 3.11 + pytest + eval + load_test smoke）和 `frontend`（Node 20 + npm ci + build）两套 job。
- `scripts/` 下三个独立可执行脚本：
  - `check.sh`：本地一键入口，按顺序串联后端 API 测试、检索评估 (`tests/eval.py`)、并发压测冒烟 (`tests/load_test.py`)、前端构建、知识库重复 FAQ 检测 (`tools/check_duplicates.py`)，通过子进程切换至 `backend/`、`frontend/` 目录执行。
  - `healthcheck.py`：纯 Python 巡检器，通过 `urllib.request` 调用后端 `/health`、`/api/v1/ops/stats`、`/api/v1/ops/handovers`、`/api/v1/ops/badcases` 等接口并运行 `backend/tests/eval.py`，将结果写入 `backend/logs/healthcheck-YYYY-MM-DD.json`；支持 `--cron` 模式并通过环境变量 `WECHAT_WEBHOOK` / `DINGTALK_WEBHOOK` 推送企微/钉钉告警。
  - `install-cron.sh`：封装 `crontab` 安装/卸载逻辑，默认每天 08:00 调度 `healthcheck.py --cron`，透传 webhook 与阈值相关环境变量。
依赖方向单向指向项目根下的 `backend/` 与 `frontend/`，脚本之间无相互依赖。
