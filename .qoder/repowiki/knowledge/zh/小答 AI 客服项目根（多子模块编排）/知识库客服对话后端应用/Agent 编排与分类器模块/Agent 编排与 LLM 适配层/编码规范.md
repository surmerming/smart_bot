- 对外异步接口统一返回 `AsyncGenerator[dict, None]`，并以固定三态事件 `{type: meta|text|done}` 驱动 SSE 流式响应。
- LLM 调用通过单例 `llm.complete(stream_chat)` 访问，禁止直接实例化 `DeepSeekClient`/`MockLLM`，保证生产与 Mock 路径一致。
- 长任务（情绪分类、查询改写、NLI、can_answer）使用 `asyncio.create_task` 并行执行并在红灯/熔断场景下显式 `cancel()` 取消，避免无效开销。
- 面向 LLM 的 prompt 集中放在 `app.agent.prompts` 常量中，运行时通过 `.format(...)` 注入上下文，避免在业务代码里内嵌字符串模板。
- 所有外部 LLM 调用均包裹 try/except 并以 `logger.warning` 记录失败后返回兜底结果，保证单点故障不影响主流程。
