三个并列的无状态分类模块，统一通过 `app.agent.llm.llm.complete` 调用大模型，并通过 `app.agent.prompts` 注入 Prompt：
- `intent.py` 是主入口，实现两级决策矩阵（相似度阈值 + LLM can_answer + NLI 蕴含校验）与可选 query rewrite；依赖 `app.storage.kb` 中的 FAQItem、negation/risk/human 等词表检测。
- `emotion.py` 基于 EMOTION_PROMPT 输出 LEVEL_0~3，LLM 不可用时回退到内置红/黄关键词与风险词库。
- `humor.py` 对事实版答案做 POLISH_PROMPT 幽默润色，并用正则指纹抽取数字/单位比对前后一致性，不一致或长度暴增则回退原答案。
所有 LLM 调用均包裹 try/except，失败时记录 warning 日志并回退到确定性规则，确保检索链路在离线/降级场景下仍可运行。
