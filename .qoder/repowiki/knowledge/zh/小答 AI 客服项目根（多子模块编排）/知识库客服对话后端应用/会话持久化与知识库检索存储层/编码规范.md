- 模块级单例：每个子系统在文件末尾导出一个全局实例（如 `answer_cache`、`rate_limiter`、`runtime`），调用方直接 import 使用而非构造对象。
- 配置集中从 `app.config.settings` 读取，模块不直接解析命令行或环境变量。
- SQLite 写入统一包裹在 `with self._lock:` 临界区内，每次查询/写入都通过 `_connect()` 获取新连接并在完成后显式 `conn.close()`，避免跨线程共享连接。
- 数据库变更采用 DDL + 运行时列检测迁移双保险：新建表用 `CREATE TABLE IF NOT EXISTS`，新增列通过 `PRAGMA table_info` 判断后 `ALTER TABLE ADD COLUMN`。
- 对外返回的 JSON 字段统一用 `to_dict` / `state` 方法序列化，避免直接暴露内部属性。
