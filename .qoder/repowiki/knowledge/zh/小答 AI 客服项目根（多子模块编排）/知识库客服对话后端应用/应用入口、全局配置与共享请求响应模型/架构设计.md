模块由三个职责清晰的子文件组成：
- `config.py` 通过 `python-dotenv` 在 `backend/.env` 中加载配置，定义强类型 `Settings` 类（DeepSeek LLM、检索阈值、会话安全、存储路径、访客 Token、OTP、灰度等），并通过 `_env_str/_env_int/_env_float` 工具函数提供带默认值的读取器，最终导出单例 `settings`。
- `main.py` 是 FastAPI 应用装配层：创建 `app`、注册 CORS 中间件、启动时一次性加载知识库 (`kb.load`)、注册基于 IP 的网关级限流中间件（`/api/` 前缀，10 次/分钟）、暴露 `/health` 健康检查，并延迟导入 `app.routers` 中的 chat/kb_admin/ops/otp/session/ws 六个子路由后统一 `include_router`。
- `models/schemas.py` 集中所有 Pydantic `BaseModel`，作为前后端 API 契约的唯一来源，按「请求 / V2.0 知识库后台 / 运行控制 / Bad Case / CSAT / OTP / 响应」分组，字段使用 `Field(..., min_length/max_length)` 做入参校验。
依赖方向单向：`main.py` → `config.Settings` + `app.storage.*` + `app.routers.*`；`schemas.py` 不反向依赖业务模块。
